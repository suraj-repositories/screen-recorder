## Download the source

1. Open the [Screen Recorder Github Repository](https://github.com/suraj-repositories/screen-recorder) in your browser. 
2. Select **Code**, then choose **Download ZIP**, or clone it with Git.
3. Extract the project to a location you can access from Eclipse.
4. Continue with [Setup in Eclipse](https://box.oranbyte.com/box/docs/screenrecorder/v1.0.0/getting-started/setup-in-eclipse).

The application is currently Windows-first. A Windows environment is required for WASAPI system-audio capture and Windows native integration.

## Before running

Install Java 22 or later and download the libraries listed in [Dependencies](Dependencies.md). The project also expects the native libraries required by the media and Windows integration dependencies.
