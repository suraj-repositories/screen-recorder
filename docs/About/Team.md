# Team

## Project

Screen Recorder is developed under the **OranByte** project namespace. The application is maintained as a Java desktop project focused on screen capture, audio recording, playback, and local file sharing.

## Contributions

The repository does not currently include a public contributor list or a defined contribution process. Changes should follow the existing Java and documentation structure, preserve Windows-specific behavior where applicable, and include documentation or tests when a change affects user workflows.

For technical context, see [Technical Overview](https://box.oranbyte.com/box/docs/screenrecorder/v1.0.0/about/technical-overview). For setup information, see [Setup in Eclipse](https://box.oranbyte.com/box/docs/screenrecorder/v1.0.0/).
