# Social media sharing, file manager, and media player

After a capture finishes, click the share button to open the sharing dialog. The selected file is shown with its name and size.

## Social media and email

The dialog provides buttons for:

- **WhatsApp**: opens WhatsApp Web with a prepared message.
- **Telegram**: opens the Telegram share URL with the file reference and message.
- **Email**: opens the system mail handler when available, with a subject, message, and local file path.
- **Twitter / X**: opens the post composer with a prepared message.

The file is also copied to the system clipboard before the web or mail handler opens, so paste it into the destination when the service supports file attachments. These actions depend on the browser, desktop mail client, or platform handler installed on the computer.

## File manager

Select **File Manager** to reveal the captured file in the operating system's file manager. On Windows, the application opens Explorer and selects the file. On macOS it uses Finder's reveal action; on other systems it opens the containing directory when supported.

## Media player

Select **Media Viewer** to open the captured file with the desktop's associated application. Videos are also available in Screen Recorder's built-in JavaFX media player after recording. Screenshots open with the associated image viewer when launched through the desktop action.

## Clipboard copy

Use the copy button in the file card or the main toolbar to put the captured file on the system clipboard. You can then paste it into a file manager, mail client, or application that accepts files.
