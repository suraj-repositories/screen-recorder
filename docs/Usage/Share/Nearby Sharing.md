# Nearby Sharing

Nearby sharing uses the LocalSend provider to find devices on the local network and transfer the selected screenshot or recording.

1. Finish a screenshot or video capture.
2. Click the share button in the main toolbar.
3. Select **Nearby Sharing**.
4. Keep the receiving device on the same local network and running a compatible LocalSend service.
5. Click the scan/refresh control if the device list is empty.
6. Select a discovered device to start the transfer.
7. Watch the progress indicator and cancel the transfer if necessary.

## Troubleshooting

- Confirm both devices are connected to the same network.
- Allow Screen Recorder through the Windows firewall when prompted.
- Disable network isolation on guest or public Wi-Fi networks.
- Refresh discovery after the receiving device becomes available.

Discovery and transfer can fail when multicast, subnet scanning, HTTPS communication, or firewall rules are blocked. No cloud account is required by the application flow.
