# Record voice

Screen Recorder does not currently provide a separate voice-only recording mode. Voice is captured as the microphone audio track of a video recording.

1. Select `Video` mode.
2. Select a capture area and click **New**.
3. Enable the microphone button before or during recording.
4. Click **Start**, speak into the selected Windows microphone, and click **Stop** when finished.
5. Open the resulting MP4 in the built-in media player or use the sharing actions.

## Troubleshooting microphone audio

- Confirm that Windows detects the microphone.
- Allow microphone access for desktop applications in Windows privacy settings.
- Check that the microphone toggle is enabled.
- Remember that the output is an MP4 with video and audio, not a standalone audio file.

Microphone and system-audio sources can be enabled independently. The audio stream is created when recording starts, so disabling a source during a recording leaves that source silent in the mixed stream.
